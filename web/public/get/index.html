📱 iPhone / iPad Your device

Runs in Safari right on vitaminshoppe.com — no other phone needed.

  1. Install the free Userscripts app.
    Get Userscripts
  2. Open Settings → Apps → Safari → Extensions → Userscripts (older iOS: Settings → Safari → Extensions), turn it on and set vitaminshoppe.com to Allow. (Open the Userscripts app once and tap “Set Userscripts Directory” if it asks.)
  3. Open the script in Safari, tap the ᴀA / puzzle icon in the address bar → Userscripts → Install.
    Install VS Clearance
  4. Shop: open Vitamin Shoppe and tap the green 🏷️ Deals button.
    Open Vitamin Shoppe

Tip: add Vitamin Shoppe to your Home Screen from Safari's Share menu so Deals is one tap away.

💻 Windows / Mac Your device

Edge, Chrome or Firefox on a computer.

  1. Add the free Tampermonkey extension.
    Edge Chrome Firefox
  2. Install the script (Tampermonkey opens an Install page).
    Install VS Clearance
  3. Open Vitamin Shoppe and click 🏷️ Deals in the corner.
    Open Vitamin Shoppe

Chrome/Edge may ask you to turn on “Allow user scripts” for Tampermonkey (Extensions → Tampermonkey → Details).

🤖 Android Your device

A full app with store pickup stock, saved filters and offline mode.

Download the app (APK)

Allow “Install unknown apps” for your browser when asked. The userscript route above works on Android too (Firefox + Tampermonkey).

🔒 Why it works this way

Vitamin Shoppe blocks servers and bots, so VS Clearance runs in your own browser while you're on their site, exactly like browsing yourself. Your filters and store stay on your device unless you choose to share your list, and links go straight to the real product pages.

What's inside & how to run your own
  • app/ — Android app (Kotlin + Jetpack Compose). Open in Android Studio, or gradlew assembleEveryoneDebug.
  • web/userscript/ — the iPhone/PC version; node web/scripts/build-userscript.mjs builds vs-clearance.user.js.
  • web/ — this share page: npm start (Node 18+, no dependencies) serves it on port 5050. web/scripts/serve.ps1 puts it online with Tailscale Funnel.
  • Start with README.md (Android) and web/README.md (iPhone, PC and the share page); npm test in web/ runs the web tests.
